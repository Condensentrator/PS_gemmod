# 宝石培育 · 基础测试包（GemBasic v1.2.0）

最基础的闭环 + 重量/阶段成长 + 水质成分决定宝石种类。

## 内容

| 物品 | 说明 |
|---|---|
| 刚玉晶核 `gem_core` | 一次性种子，种类由培养液成分决定 |
| 红宝石晶核 `gem_core_ruby` | 一次性种子，固定长成红宝石 |
| 绿柱石晶核 `gem_core_beryl` | 一次性种子，长出绿柱石（祖母绿/海蓝/摩根石/金绿柱石） |
| 刚玉 / 绿柱石（小/中/大/巨） | 每种矿物×颜色一套**预染色图标和物品 id**；运行时不再改颜色 |
| 基础结晶槽 `gem_growth_basic` | 自建机器：**专用水槽（只收液体容器）+ 5×5 材料区（只收带 `GEM_ITEM` 标签的物品，输入输出共用）** |
| 测试用水 | 锈水 / 富矿物 / 富化学 / 金属+矿物 / 金属+化学 / 富植物(杂质) |

## 成分 → 颜色

颜色只看**无机成分的比例**，有机物只当杂质：

| 无机成分 | 刚玉 | 绿柱石 |
|---|---|---|
| 重金属 ≥50% | 红宝石 | 祖母绿 |
| 矿物 ≥50% | 蓝宝石 | 海蓝宝石 |
| 化学 ≥50% | 绿色蓝宝石 | 摩根石 |
| 重金属 + 矿物（无过半） | 黄色蓝宝石 | 金绿柱石 |
| 重金属 + 化学（无过半） | 粉色蓝宝石 | 摩根石 |
| 矿物 + 化学（无过半） | 绿色蓝宝石 | 祖母绿 |

- 三项都低于 0.5 ml 时随机；
- 颜色由预染色贴图承载：决定颜色后直接生成对应的彩色物品；
- **植物/有机废物不参与颜色**，只作为杂质降低每日生长速度（最多 -60%）；
- 旧的红宝石晶核 `gem_core_ruby` 固定出红宝石；
- 价格（信用点/kg）：刚玉 红3000 / 蓝3600 / 绿3200 / 黄4000 / 粉4500；绿柱石 祖母绿5000 / 海蓝4200 / 摩根石4800 / 金绿柱石4000；
- 日志会打印 `金属X 矿物Y 化学Z 有机W ml`。

## 重量规则

- 晶核长成小宝石：随机 **30–70 g**（2 天）；
- 宝石留在槽里：**每天**增重一次，上限 **600 g**；
- 重量跨过 **80 / 200 / 400 g** 时，自动换成中/大/巨阶段，形状和贴图一起变；
- 价格按重量算：**3000 信用点/kg**（30g=90，200g=600，600g=1800）；
- tooltip 显示 **"重量：XX g"**；价值是信用点，不是克数。

## 水质规则（v0.4 新增）

- 结晶槽里必须有 **≥100 ml** 的水，否则生长暂停；
- 每次成功生长扣 **100 ml**；
- 纯度影响每日涨幅：
  - **≥70%**：6%/天（加速）
  - **30–69%**：4%/天
  - **<30%**：2%/天（减速）
- 宝石 tooltip 会显示上一次培养液的信息：
  `培养液：纯度 98.37%　矿物 1.2 ml　重金属 23.7 ml`
  （`GetWaterPurity` 返回的是 0–10000 刻度，9837 实际是 98.37%）
- 水可以是任何液体容器（瓶装水、水罐、净化水、自己灌的水）；水用完后瓶子会空。

## 标签：可见类型 vs 自定义判定标签

- `Types` 是游戏可见的物品类型（例如 `LUXURY_ITEM` 奢侈品、`MATERIAL` 材料），用于分类/提示；
- `AdditionalTags` 是自定义状态标签，不占类型栏，用于逻辑判定：
  - `GEM_ITEM`：所有晶核/宝石共有的"培育材料"标签，**材料区按它放行**；
  - `GEM_CORE`：晶核；
  - `GEM_CULTURED`：培育宝石。
- 以后加新宝石，只要在 `AdditionalTags` 里带 `GEM_ITEM`，材料区就会自动接受；不需要再改白名单。
- 旧版本的晶核/宝石会在读档/新档/每天开始时自动补上 `GEM_ITEM` 标签。

## 怎么试

1. 重启游戏，读档或开新档。
2. 读档/开档/每天开始时，自动把 **1 台结晶槽 + 4 枚晶核 + 3 瓶水** 放到柜台上（已属于你）。
3. 把结晶槽摆到店里，打开：**水瓶放进专用水槽**（只收带 `LIQUID_CONTAINER_TAG` 的液体容器），**晶核/宝石放进 5×5 物品区**。
4. 过 2 天，晶核变成小宝石；继续留在里面，**每天**长大一点。
5. 水不够时生长暂停，往水槽里换一瓶水即可。
6. 成品会留在物品区，不需要单独领取；想停就拿出来，放回去会继续长。

> v0.5 及以前用水培机克隆的旧结晶槽是占位符，没有实际功能。
> 请把旧结晶槽丢掉，睡一天会补发新的自建结晶槽；旧档里的旧宝石/晶核可以继续用。

## 这一版没有的东西

- 没有按具体成分改变颜色/种类（目前只把成分显示出来，并让纯度影响速度）
- 没有退火、变异、模组、商人供货、原石/鉴定/切割
- 晶核一次性消耗，补货靠自动发放（仅测试用）

## 卸载

删除 `Mods/PSItemPack_GemBasic.dll` 即可。建议先把宝石/晶核/水处理掉，免得变成未知物品。
